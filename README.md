## 📌 Temel IT ve Ağ Komutları
- **`ipconfig`**: Bilgisayarın yerel IP adresini ve Ağ Geçidini (Gateway) gösterir.
- **`ping [IP/Domain]`**: Hedef sistemle bağlantı durumunu ve erişim süresini ölçer.
- **`netstat`**: Bilgisayardaki aktif ağ bağlantılarını ve açık portları listeler.
